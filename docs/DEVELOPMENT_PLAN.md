# 玩伴島：實作範圍及逐階段驗收

## 技術決策

採用指定的 Expo / React Native / TypeScript、Next.js、NestJS、PostgreSQL 與 Socket.IO。這個平台需要常駐連線和之後的遊戲時鐘，後端採用常駐 Docker 服務。PostgreSQL 是帳號、房間及交易的權威資料來源。Redis 目前提供 Socket.IO 跨服務廣播介面；單機開發可不啟用，尚未實測的多節點能力不列為完成。

LiveKit 及 S3 已保留環境變數位置，但**本階段尚未整合**。語音需另行部署可對外連線的 LiveKit/TURN、簽發短期房間權限及真機驗收；物件儲存需預簽上傳、大小與類型限制及內容審核。採原創品牌及前期已產生的原創插畫，不引用 WePlay 素材。

## 第一階段：帳號、大廳、房間（本次範圍）

- 註冊、登入、訪客、永久 UID、暱稱和頭像色編輯；等級依伺服器經驗值換算，尚未發放經驗值。
- scrypt 密碼雜湊、15 分鐘 Access JWT、30 天不透明 Refresh Token、雜湊儲存、單次輪替、重播撤銷同一 token family。
- 原創深色手機介面、實際餘額（初始為 0）、真實公開房間與實際 Socket 使用者數。無假好友、假玩家或填充公告。
- 建立、密碼加入、邀請碼加入私人房、離房、容量及座位鎖、房主移轉、房主移除／封鎖玩家、持久化文字聊天、重連恢復。
- 管理員建立指令、玩家停權／恢復、房間列表、線上人數、公告及稽核紀錄。一般玩家不可呼叫管理 API。
- 尚未提供：自訂頭像上傳、改密碼、忘記密碼、信箱驗證、多因子驗證、訪客轉正式帳號、資料刪除／匯出／申訴。這些是後續發佈門檻。

### 房間狀態及連線政策

```
waiting --最後一人離房--> closed
waiting --遊戲引擎（後續）--> playing --結算（後續）--> waiting
```

本版僅允許 `social` 文字派對。其他遊戲類型資料欄位是擴充點，建立 API 會拒絕未實作的模式。`playing` 為保留狀態，沒有假遊戲開始按鈕。

一個玩家最多在一間房。建立／進房使用資料庫交易、玩家鎖和房間鎖，座位有唯一索引。短暫斷線保留座位與房主，重新連線自動恢復訂閱；需明確離房或被房主移除才釋放座位。離房時房主交給最早加入的剩餘玩家；最後一人離開關閉房間。尚未實作長期離線自動清理，雲端公開前需完成保留時間與房主離線政策。

Socket 訊息每次重新檢查 token 與資料庫會員資格。訊息逾時時先查看紀錄，再決定重送；本版未提供聊天 client-message-id 去重。沒有語音時不顯示可操作的麥克風控制。

## 後續順序與完成門檻

| 階段 | 實作範圍 | 必須通過的驗收 |
|---|---|---|
| 2 | 誰是臥底：4–12 人、私有詞語、輪流發言、計時、投票、平票、淘汰、勝負、下一局 | 伺服器狀態機、每個階段重連、惡意事件拒絕、至少 4 個真帳號完整一局 |
| 3 | LiveKit 語音、房主禁言、座位／麥克風權限 | 兩支不同網路真機、鎖屏／切換背景／拒絕權限／TURN／重連驗證 |
| 4 | 你畫我猜：同步畫布、伺服器題目與計分、回合與結算 | 至少 3 人多輪、繪圖速率限制、答案保密、斷線恢復 |
| 5 | 狼人殺角色、夜間／白天、死亡權限、勝負 | 每種角色行動及邊界案例、資訊隔離、獵人／女巫交互測試 |
| 6 | 好友、私訊、通知、封鎖、檢舉、群組、貼文 | 封鎖隔離、上傳安全、內容治理、通知交付實機測試 |
| 7 | 測試幣任務、每日獎勵、背包、禮物、商城 | Ledger 與餘額同一交易、冪等、併發扣款／領獎不重複，保持無真金流 |
| 8 | 原創太空推理、合法歌曲搶唱 | 專屬遊戲狀態機、授權清單、多人及延遲測試 |

每階段都需建置、自動測試、測試報告及清楚的未完成清單。不能以第一階段宣稱達到 WePlay 90%。

## 後續遊戲擴充契約

遊戲放入 `apps/api/src/games/<game>/` 獨立 Nest module，實作 `createState / applyAction / onTimeout / publicView / privateView / reconnectView`。輸入只包含動作，伺服器決定角色、詞語、時鐘、得分和勝負。每個狀態有版本號；用 PostgreSQL 事件／快照持久化，Redis 做短期快取與計時任務協調，不能只放 process 記憶體。隱藏資訊不得出現在廣播快照；多節點須用分散式鎖或單房間 owner 排程，先加入重播與恢復測試才接 UI。

## 部署與發佈門檻

Docker Compose 是部署來源，不代表已部署。需雲端主機、網域、HTTPS/WSS reverse proxy、備份還原演練、祕密管理、資料庫 least-privilege 帳號、監控與告警、Redis 故障測試及容量測試。本機驗證未使用 Docker，不能宣稱容器已實測。

Expo 原始碼可建立 Android / iOS 原生 App，但本次未產出 APK / IPA，也未完成 App Store / Google Play 審核。正式 iPhone 安裝需 Apple 帳號及簽章；雲端建置需使用者自己的 EAS 專案和環境變數。未驗證的真機行為不能以 Web 驗收取代。

安全發佈前必須補上信箱驗證／找回、刪除與匯出、隱私政策及申訴入口、內容審核、admin MFA 與更細 RBAC、依賴安全稽核、備份／復原、併發壓測及可觀測性。僅提供測試幣，不接真實付款。
